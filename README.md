# CS-300 Data Structures and Algorithms Portfolio Reflection

## 1. What was the problem you were solving in the projects for this course?

The problem I was solving throughout this course was determining the best way to store, organize, and retrieve course information. As I worked through the projects, I learned that building a program is not just about making it work. It is also about understanding how the program will be used in the future and selecting the most functional and efficient solution to support those needs. This required analyzing different data structures and determining which one would best support searching, sorting, and maintaining course data.

---

## 2. How did you approach the problem? Consider why data structures are important to understand.

I approached the problem by understanding that I could create an algorithm that would capture, retain, organize, and display information when prompted by the user. Data structures are important because they provide the framework that allows data to be stored and accessed efficiently. By learning how different data structures work, I was able to better understand how to design a program that could manage course information effectively while maintaining good performance.

---

## 3. How did you overcome any roadblocks you encountered while going through the activities or project?

When I encountered roadblocks, I overcame them by repeatedly reviewing my work until I found the source of the problem. Rather than immediately looking for a completely new solution, I learned the value of carefully examining my code, testing individual sections, and tracing the program's behavior. This process helped me identify mistakes, strengthen my debugging skills, and gain confidence in solving problems independently.

---

## 4. How has your work on this project expanded your approach to designing software and developing programs?

This project expanded my approach to software development by teaching me how to break large problems down into smaller pieces. Instead of focusing only on the big picture, I learned to identify the smaller solutions that contribute to the overall result. This approach has helped me become more methodical when designing software and has improved my ability to solve complex programming challenges one step at a time.

---

## 5. How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

Through this course, I have started to recognize that there are patterns, or "shapes," in programming. These shapes are created by control structures such as if statements, else statements, for loops, while loops, and nested logic. As I have gained more experience reading and writing code, I have become better at recognizing these patterns and understanding how they work together. This awareness helps me write programs that are more organized, readable, and adaptable because I can structure code in a way that is easier to follow, maintain, and modify in the future.
